# Zimbra 9 Open Source — instalación histórica

**Legacy.** Este documento conserva una guía basada en material histórico de Zimbra 9 Open Source de Zextras.

| Plataforma | Paquete |
|---|---|
| RHEL 8 | `zcs-9.0.0_OSE_RHEL8_latest-zextras.tgz` |
| RHEL 7 | `zcs-9.0.0_OSE_RHEL7_latest-zextras.tgz` |
| Ubuntu 20 | `zcs-9.0.0_OSE_UBUNTU20_latest-zextras.tgz` |
| Ubuntu 18 | `zcs-9.0.0_OSE_UBUNTU18_latest-zextras.tgz` |

## Flujo

1. Descargar el paquete correspondiente desde el proveedor.
2. Como `root`, descomprimirlo en una ruta de trabajo.
3. Entrar al directorio creado.
4. Ejecutar `install.sh`.
5. Completar el instalador.

Los enlaces privados/tokenizados del documento original no se incluyen en el repositorio.
