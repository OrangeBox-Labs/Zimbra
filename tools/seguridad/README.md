# Seguridad

Herramientas y procedimientos de seguridad relacionados con autenticación de correo y servicios de Zimbra.

| Herramienta | Qué hace |
|---|---|
| `zimbra-dkim.sh` | Crea, consulta, actualiza o elimina DKIM por dominio. |
| `zimbra-desactivar-av-antispam.sh` | Activa o desactiva antivirus y antispam del servidor. |
