# Certificados

Herramientas para certificados TLS de Zimbra.

| Herramienta | Qué hace |
|---|---|
| `certbot-zimbra.sh` | Obtiene/renueva y despliega certificados Let's Encrypt. |
| `zimbra-autofirmado.sh` | Genera y despliega un certificado autofirmado. |
| `zimbra-certificado-comercial.sh` | Verifica y despliega un certificado comercial. |
