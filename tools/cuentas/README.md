# Cuentas y buzones

Herramientas para cuentas, aliases, estados, cuotas y consultas de mailboxes.

| Herramienta | Qué hace |
|---|---|
| `zimbra-alias.sh` | Crea aliases de una cuenta. |
| `zimbra-account-status.sh` | Cambia el estado de una cuenta. |
| `zimbra-password-locked.sh` | Configura `zimbraPasswordLocked` en un COS. |
| `reporte-uso-cuentas.sh` | Genera un reporte de uso de mailboxes. |
| `listar-carpetas-usuarios.sh` | Lista carpetas de todos los usuarios. |
