# CentOS 8 Stream y compatibilidad de instaladores

**Legacy / workaround histórico.**

La guía original registraba un instalador que identificaba el sistema como `UNKNOWN64` y señalaba como workaround reemplazar `Stream` por `Linux` en los archivos `/etc/redhat-release`.

Este procedimiento altera la identificación del sistema operativo y puede afectar otras herramientas que dependan de esa información. No debe aplicarse a ciegas.

Se conserva aquí únicamente como referencia histórica para troubleshooting de instaladores antiguos.
