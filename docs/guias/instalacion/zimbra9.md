## Flujo

1. Descargar el paquete correspondiente desde el proveedor.
2. Como `root`, descomprimirlo en una ruta de trabajo.
3. Entrar al directorio creado.
4. Ejecutar `install.sh`.
5. Completar el instalador.

La fuente original proviene de un correo histórico de distribución de Zimbra 9. Verifica disponibilidad, soporte y documentación del producto antes de usar este procedimiento.
